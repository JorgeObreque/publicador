# Meta Ads

Variables requeridas:

- `META_API_VERSION`
- `META_ACCESS_TOKEN`
- `META_AD_ACCOUNT_ID`
- `META_APP_ID`
- `META_APP_SECRET`

## Flujo de publicación

1. La campaña se crea en estado `PAUSED`.
2. El operador revisa anuncios y creativos.
3. La activación es explícita desde el panel.
4. Solo entonces Meta comienza a cobrar.
